# 🍽️ Swiggy Menu API - AWS Serverless Project

## 📌 Overview

This project demonstrates a serverless REST API that returns a restaurant menu using AWS Lambda and API Gateway.

## 🚀 Features

* GET `/menu` endpoint
* Returns menu items with prices
* Random Today's Special
* Restaurant rating
* Serverless architecture

## 🛠️ Tech Stack

* AWS Lambda
* Amazon API Gateway
* Python
* JSON
* Postman

## 🏗️ Architecture

Client
⬇️
API Gateway
⬇️
AWS Lambda
⬇️
Generate Menu Response
⬇️
Return JSON Response
